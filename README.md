# Ficha Técnica de Indicadores de Riesgo

Aplicación React + Vite para construir fichas técnicas institucionales de indicadores de riesgo.

## Comandos

```bash
npm install
npm run dev
```

Luego abrir la URL que muestre la terminal, normalmente:

```text
http://localhost:5173/
```

## Compilar para producción

```bash
npm run build
```

La carpeta final queda en:

```text
dist/
```

## Vista local de producción

```bash
npm run preview
```
